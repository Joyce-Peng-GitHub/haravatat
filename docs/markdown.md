# Markdown 写作语法

支持 CommonMark 与 GFM，包括表格、自动链接、任务列表、脚注、`~~删除线~~`。高亮用 `==文字==`，也可用 `==**重要文字**==`。

## 数学公式

行内公式支持 `$\LaTeX$` 或 `\(E=mc^2\)`。显示公式可以使用 `$$...$$`（同一行或多行）、`\[...\]`，或者 `math` 代码块：

````markdown
行内 $\LaTeX$ 与 \(a_1 + b_2\)。

$$
\sum_{i=1}^n i = \frac{n(n+1)}{2}
$$

\[\int_0^1 x^2\,dx = \frac{1}{3}\]

```math
\begin{aligned}
a &= b+c \\
d &= e+f
\end{aligned}
```
````

由 KaTeX 排版，并非完整 LaTeX 文档编译器，不支持任意宏包、文件读取或联网命令。错误公式保留可见原文及错误提示；其他正文可继续阅读。普通围栏代码块与行内代码不渲染其中的数学标记。文字中的美元符号可写为 `\$`。

## 提示块

引用块的第一行写 `[!NOTE]`、`[!TIP]`、`[!IMPORTANT]`、`[!WARNING]` 或 `[!CAUTION]`，后面继续普通 Markdown：

```markdown
> [!NOTE]
> 支持 **粗体**、==高亮== 和 $x^2$。
>
> - 第一项
> - 第二项
```

原始 HTML 不执行。相对图片及文章链接会在发布时解析为公开快照，未发布的依赖文件不会因此公开。数学解析规则与资源隔离见 publishing.md。

升级前生成的发布快照可能已经转义了公式标记；若旧文章显示不正确，请从工作台重新发布。刷新阅读页不会重新生成历史快照。同样，安装新的 Typst 字体后需重新发布，才能更新已保存的 PDF。

## 脚注导航

使用 `正文[^note]` 和 `[^note]: 注释内容` 定义脚注。点击正文编号跳至脚注，点击脚注后的返回箭头回到相应引用位置；同一脚注多次引用时各有独立返回链接。阅读组件保留生成的链接 ID、脚注属性及可访问性属性，确保箭头有实际定位目标。已有发布文章刷新阅读页即可获得修复，无需重新发布。

## 文章目录

在正文中独占一段写 `[TOC]`（也接受 `[toc]`），与前后内容用空行分隔，即可在该位置生成可点击的分级目录：

```markdown
# 我的文章

[TOC]

## 第一部分

正文。

### 深入讨论

## 第二部分
```

目录包含正文一至六级标题，按实际标题层级嵌套；跳级标题仍按最近的较高层标题归属。中文、行内格式、代码和数学标题均可生成目录文字；目录文字使用纯文本，图片使用替代文字。重复或仅标点的标题会获得唯一锚点，不会跳到另一个同名标题。脚注定义中的标题和自动生成的脚注区标题不纳入目录。

只识别文章顶层、独占段落的标记，代码块、行内代码、引用块及普通句子中的 `[TOC]` 保持原样。多个标记可分别显示完整目录，没有标题时不显示目录框。无标记的文章仍为标题生成锚点，便于手写链接。

标题锚点使用 `heading-` 前缀，标题经 Unicode 规范化、转小写、去除标点并把空格替换成 `-`；重复时依次附加 `-1`、`-2` 等，纯标点使用 `heading-section`。可复制目录链接分享；首次打开带锚点的网址或刷新后，会在文章加载完成时定位。目录在阅读时生成，已有发布快照中的标记刷新后即可生效。
