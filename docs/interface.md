# 使用界面

首页公开列出文章，显示来源、格式、作者和日期，支持按 GitHub 作者过滤与分页。无需登录即可阅读。桌面/手机使用同一套布局。

GitHub 登录后进入「我的工作台」：

1. 新建「上传工作区」，或提供任意公网 HTTPS Git 克隆地址与分支名，并可选填完整 Commit SHA；私有仓库同步时输入用户名与 token。
2. 上传文件/整个目录；可选目标目录前缀。仓库来源点击「同步仓库」。
3. 上传来源支持新建/编辑文本、下载、删除文件、移动文件或目录；仓库来源只读。
4. 勾选 Typst / Markdown 入口，可修改文章标题，点击「发布所选文章」。未勾选的已发布文章会下架。
5. 操作错误与 Typst 诊断在界面显示。取消勾选全部入口会在发布前确认；删除文件/来源也显示确认提示。

草稿下载要求登录。文件和图片可作为 Typst 编译依赖，但不能单独作为文章入口。一次上传/编辑/同步后需重新发布。勾选和标题是未保存的界面状态；重新加载/切换来源或修改草稿会重置到上次已发布选择，请先完成文件操作再勾选。

PDF.js 将各页 canvas 与文字层竖向紧贴排列，不创建工具栏、iframe 或独立滚动窗口。支持选择复制文字、PDF 外部链接和文内链接；视口附近按需渲染，离开附近区域释放 canvas 内存，宽度变化会重新渲染。每页像素数上限 1200 万，设备像素比上限 2。加载失败提供 PDF 下载链接。

Markdown 使用 GFM（表格、任务列表、删除线等），支持引用式图片、可滚动代码和表格，禁用原始 HTML。Typography 使用本地系统字体；中文衬线字体作为可选美化，不要求第三方网络字体。

PDF.js 6 的 worker、CMap、标准字体与 WASM 解码器随构建部署到 /pdf-assets，不依赖 CDN。文字层使用当前版本 --total-scale-factor 与舍入变量。生产 CSP 仅允许本站 JS 与 WASM 执行，禁止内嵌脚本。

浏览器验证使用隔离测试服务器：真实 API、PostgreSQL WASM 存储、真实 Typst 编译与 React/PDF.js；仅 GitHub OAuth 外部身份交换和远端仓库下载注入固定测试实现，不改变生产应用登录规则。测试覆盖公开 Markdown、两页 PDF 连续排列、文字层、390px 手机无横向溢出、OAuth 回调、上传、勾选发布、仓库同步和 HTML 脚本禁用。examples/ 提供可上传示例，不自动写入生产数据库。

补充浏览器验证：带目录前缀的 multipart 上传、编辑草稿、混合 Typst/Markdown 发布、真实 Typst 页面渲染、私有仓库 token 输入与清空，以及手机工作台无横向溢出。

npm run test:e2e:production 在 npm run build 后直接用 Fastify 提供 dist 静态文件，以相同浏览器流程验证生产资源路径、CSP、PDF worker/字体/WASM 和 SPA 路由回退。此测试仍使用隔离测试身份，不代表真实 OAuth App 的线上配置已完成。

仓库工作区统一显示为 Git 仓库，兼容旧 GitHub 来源。同步区域可编辑 Commit SHA：填入完整 40/64 位 SHA 固定到指定提交，清空恢复跟随分支。上方短 SHA 为实际同步结果。认证输入在同步成功和切换工作区后清空；Commit 目标保存于来源。新建来源同样提供可选 Commit 输入。窄屏下同步字段竖向排列。

浏览器测试默认使用 API 3000 端口；本机已有 Compose 服务时可设置 E2E_API_PORT=3100，开发与生产静态页面两套测试均支持。

PDF 窗口缩放检查等待 ResizeObserver 更新页面宽度后断言，避免把尚未完成的缩放当作横向溢出。

入口选择使用可折叠文件树，目录排在文件前，叶节点显示文件名，悬停可见完整路径。支持展开/收起全部；筛选按完整路径匹配并自动展开匹配文件的祖先目录，清空筛选恢复之前的折叠状态。折叠和筛选不改变入口勾选与文章标题。目录使用有 aria-expanded 的原生按钮，可通过键盘操作；仅 Typst/Markdown 叶节点提供发布复选框，依赖文件仍可下载或管理。深层目录缩进有上限，避免手机布局无限向右延伸。

浏览器测试覆盖目录折叠隐藏叶节点、筛选展开匹配祖先、清除筛选与展开全部后继续选中发布，以及桌面/手机的文件管理流程。

仓库同步区提供「保存凭据 / 替换已保存凭据」「删除保存的凭据」和「打开此工作台时自动同步」。保存后清空输入框，只显示服务器是否已有加密凭据；token 留空的手动/自动同步会复用保存值，填写新值可单次覆盖。保存、删除凭据及修改自动同步设置不重置当前入口勾选或正在编辑的 Commit 输入。删除凭据同时关闭自动同步；显示最后成功同步时间。自动同步开关立即响应点击，设置保存失败时恢复原状态。

自动同步仅在进入该工作区时执行一次，先取得最新快照再展示文件树，不运行定时任务、不自动发布；失败时展示上次快照和错误提示。同 Commit 重复同步不将已发布文章误标为草稿更新。服务器未配置凭据密钥时禁用保存按钮，并保留单次输入 PAT 的同步方式。
